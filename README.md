# エネルギーの種類あて（energy-shurui）

身のまわりの場面やエネルギーの説明（高い所のおもり・転がるボール・燃やす前のガソリン など）を読んで、エネルギーの種類（位置・運動・電気・熱・化学エネルギー）を当てる1日5問の学習ゲーム。正解したら「どんなエネルギー？」（力学的エネルギーのなかま・電流がもつもの・物質や温度によるもの）も選ぶ。中学3年理科「エネルギー」。

遊ぶ: <https://satou-aaaaa.github.io/energy-shurui/>

- 中身は札幌市教育委員会の中学3年理科 学習課題「エネルギー」「エネルギーの変換」、経済産業省 資源エネルギー庁のエネルギー教育の教材、広島大学附属中・高等学校の授業実践で確かめたことだけです。
- 光・音・弾性・核エネルギーは扱いません。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
